# 알고리그

알고리그는 매일 알고리즘 문제를 풀고, 검증된 정답 기록을 쌓아 9급부터 1급까지 성장하는 개발자 학습 리그입니다. 문제 탐색과 코드 실행·제출, 자동 채점, 등급 관리, 다른 참가자의 풀이 공유를 하나의 흐름으로 제공합니다.

## 마스코트 알고달

알고달은 작은 눈과 둥근 안경이 매력적인 알고리그의 공식 마스코트입니다. 코딩을 너무 좋아한 나머지 수달왕국 곳곳에 개발 문화를 전파한 전설적인 수달로, 알고달의 활약 덕분에 수달왕국은 동물 세계 최고의 개발 왕국으로 성장했습니다. 어려운 문제를 만날 때마다 땀을 흘리면서도 끝까지 답을 찾아내며, 최근에는 인간인 척 인간들과 알고리즘 문제 풀이 대결을 펼치는 것이 알고달의 새로운 인기 취미가 되었습니다. 알고리그 참가자와 함께 공부하고 도전하며 성장하는 든든한 동료입니다.

## 주요 화면과 기능

- **로그인·회원가입**: 아이디와 비밀번호로 로그인하며 휴대폰 인증, 아이디·닉네임 중복 확인, 선호 프로그래밍 언어 설정을 지원합니다.
- **홈**: 현재 등급, 승급 진행도, 오늘의 문제, 최근 풀이 활동을 실제 사용자 데이터로 보여줍니다.
- **문제 탐색**: 내 등급을 기준으로 문제를 검색하고 등급, 풀이 상태, 정렬 조건에 따라 탐색할 수 있습니다.
- **나의 문제**: 제출하거나 해결했던 문제와 풀이 기록을 다시 확인할 수 있습니다.
- **문제 풀이**: Python, Java, JavaScript, C++과 주요 런타임 버전을 선택해 코드를 실행하고 제출할 수 있습니다.
- **풀이 공유**: 정답 제출 후 내 답안과 채점 결과를 확인하고, 다른 참가자의 풀이를 추천순·최신순·댓글순으로 살펴볼 수 있습니다.
- **랭킹·프로필**: 등급과 정답 기록을 기반으로 순위를 확인하고 프로필 사진, 닉네임, 비밀번호, 선호 언어를 관리할 수 있습니다.
- **관리자 기능**: 권한이 있는 사용자만 문제 생성 현황, 검수 및 운영 기능에 접근할 수 있습니다.

## 등급 체계

등급은 **9급부터 1급까지**이며 숫자가 작을수록 높은 등급입니다. 현재 등급의 문제뿐 아니라 한 단계 높은 문제에도 도전할 수 있고, 각 문제의 최초 정답만 승급 실적에 반영됩니다.

| 현재 등급 | 승급 조건 |
| --- | --- |
| 9급 · 8급 · 7급 | 정답 5개 |
| 6급 · 5급 | 정답 10개 |
| 4급 · 3급 | 정답 15개 |
| 2급 | 정답 20개 |
| 1급 | 정답 30개 달성 시 챔피언스 리그 참가권 획득 |

## 개발 스택

- **언어**: TypeScript 6
- **웹 프레임워크**: Next.js 16, React 19
- **UI**: Chakra UI 3, Emotion
- **인증 토큰 처리**: JOSE
- **아이콘**: Lucide React
- **품질 관리**: ESLint, Prettier, TypeScript 타입 검사
- **테스트**: Vitest, V8 Coverage
- **실행 환경**: Node.js 22 이상, Yarn 1.22
- **서비스 구성**: Fastify API, PostgreSQL, Redis 기반 작업자, Docker 채점 샌드박스와 연동

## 개발과 검증

의존성을 먼저 설치합니다.

```bash
yarn install
```

| 목적 | 명령어 | 설명 |
| --- | --- | --- |
| 개발 서버 | `yarn dev` | Webpack 기반 개발 서버를 실행합니다. |
| 프로덕션 빌드 | `yarn build` | 배포 가능한 프로덕션 번들을 생성합니다. |
| 프로덕션 실행 | `yarn start` | 빌드된 애플리케이션을 실행합니다. |
| 코드 검사 | `yarn lint` | 작명·구조 규칙과 ESLint 규칙을 함께 검사합니다. |
| 코드 정리 | `yarn format` | Prettier 규칙을 전체 코드에 적용합니다. |
| 포맷 확인 | `yarn format:check` | 파일을 변경하지 않고 포맷 준수 여부를 확인합니다. |
| 타입 검사 | `yarn typecheck` | 라우트 타입을 생성하고 TypeScript 오류를 검사합니다. |
| 테스트 | `yarn test` | 전체 단위 테스트를 한 번 실행합니다. |
| 테스트 감시 | `yarn test:watch` | 변경 사항을 감지해 관련 테스트를 반복 실행합니다. |

배포 전에는 다음 검증을 순서대로 실행하는 것을 권장합니다.

```bash
yarn format:check
yarn lint
yarn typecheck
yarn test
yarn build
```

## 대표 라이브러리

- **Next.js**는 라우팅, 서버 렌더링, 빌드와 API 프록시의 기반을 담당합니다.
- **React**는 화면을 재사용 가능한 컴포넌트 단위로 구성하고 사용자 상호작용을 관리합니다.
- **Chakra UI**는 알고리그의 공통 레이아웃, 입력 요소, 모달, 접근성 기반 UI를 제공합니다.
- **Emotion**은 Chakra UI와 함께 컴포넌트 스타일을 처리합니다.
- **JOSE**는 인증 과정에서 사용되는 JWT 관련 처리를 담당합니다.
- **Lucide React**는 일관된 형태의 인터페이스 아이콘을 제공합니다.
- **Vitest**는 기능과 정책 로직의 단위 테스트를 빠르게 실행합니다.
- **ESLint·Prettier**는 코드 규칙과 일관된 포맷을 유지합니다.
