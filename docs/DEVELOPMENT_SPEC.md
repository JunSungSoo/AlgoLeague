# Algorithm Champions 개발 명세

기준 문서는 2026-08-11 v1.3 기획서다. 이 문서는 구현 가능한 단위, 수용 기준, 시스템 경계로 분해한 기준선이다.

## 1. 출시 범위

P0 코어는 PC 웹의 계정, 홈, 문제 탐색·풀이·제출, 결과·해설, 프로필·등급, 등급별 랭킹, AI 생성 현황과 문제 검수다. P1은 알림, 무결성 사건·소명·제재, 감사 로그다. 멘토링, 월간 챔피언스 리그, 분석 고도화와 조회 전용 앱은 P2 후속 트랙이다.

현재 저장소는 P0의 실행 가능한 웹 셸, 정책 도메인, PostgreSQL 스키마, REST 경계, Redis 워커, 다언어 Docker 샌드박스, AI 생성 어댑터와 자동 검증 골격을 포함한다. 외부 인증 제공자, 실제 문제 재고 30일분, 결제·법률 문서와 운영 인프라 계정 연결은 출시 환경 작업이다.

구현 경계는 명시적으로 분리한다. 이 저장소의 `src`는 Next.js PC 웹만 소유한다. 형제 저장소 `../algorithm-champions-back`은 Fastify API, 인증·scope, PostgreSQL/Drizzle, Redis, 정책·트랜잭션 서비스와 모든 워커를 소유한다. 프런트엔드는 `NEXT_PUBLIC_API_URL`을 통한 HTTP 계약으로만 백엔드에 접근한다.

## 3. 상태 모델

채점은 `QU → RN → AC|WA|CE|RE|TLE|OLE|SE`이며 인프라 장애는 `JH`, 내부 오류는 `IE`다. `JH`와 `IE`는 제출 횟수와 실적을 변경하지 않는다.

생성은 `REQUESTED → GENERATING → GENERATED → SCHEMA_VALIDATED → COMPILED → FUZZ_VALIDATED → MUTATION_VALIDATED → REVIEW_REQUIRED|APPROVED → SCHEDULED → PUBLISHED`다. 거절 상태와 실패 리포트는 `generation_jobs`에 보존한다.

## 4. 트랜잭션 경계

최초 AC 확정은 하나의 DB 트랜잭션에서 수행한다: 제출 행 잠금 → `solved_problems` 삽입 시도 → 신규일 때 사용자 누적값 잠금·증가 → 0개 이상의 승급 이벤트 삽입 → 현재 배정 완료 → 다음 문제 배정 이벤트 발행. 모든 이벤트는 제출 ID 기반 멱등 키를 가진다.

강등 스케줄러는 대상 사용자를 `FOR UPDATE SKIP LOCKED`로 나누어 처리하고 사용자·14일 구간 기반 멱등 키를 기록한다. 문제 무효화는 해결 원장을 void 처리한 후 동일 정책 함수를 재생해 등급과 랭킹을 재구성한다.

## 5. 보안 경계

- 사용자 코드는 API 프로세스에서 실행하지 않는다. Redis 큐에는 opaque 작업 ID를 넣고 테스트 데이터는 워커에서만 조회한다.
- Docker 실행은 `--network none`, 읽기 전용 루트, capability 전체 제거, `no-new-privileges`, PID 32, CPU 1, 메모리 1 GiB, 출력 1 MiB를 강제한다. 운영에서는 Docker socket 대신 gVisor/Firecracker를 적용한 전용 노드 API로 교체한다.
- 비공개 테스트와 oracle은 응답·로그·표준 오류에 포함하지 않는다. 내부 경로를 정규화한다.
- 조회 앱 scope에는 쓰기 권한을 발급하지 않으며 서버가 scope를 검사한다.
- CSP, 속도 제한, CSRF origin 검사, 비밀 관리자, SAST/DAST, 이미지 서명은 배포 게이트에서 추가한다.

## 6. 운영 SLO 초안

일반 조회 p95 300ms, 제출 접수 p95 500ms, 일반 채점 시작 p95 5초를 베타 기준으로 측정한다. Judge, 생성 워커와 API는 각각 독립 확장한다. trace ID는 API→Queue→Worker→감사 로그 전체에 유지한다.

## 7. 후속 개발

1. 멘토링: 관계 수락·차단, AC 답안 기본 공유, 미해결 코드 열람 전 영구 랭킹 포기, immutable 코드 스냅샷과 줄 댓글.
2. 챔피언스: 월 1회, 무제한 등록, 체크인, 격리된 대회 워커 풀, 정답 수→페널티→마지막 AC 시각 순위, 검증 후 배지.
3. 조회 앱: Flutter 후보, read-only OAuth scope, 문제·해설·이력·프로필·랭킹·알림만 제공. 실행·제출은 API에서도 차단한다.

후속 착수 전 랭킹 가중치, 챔피언스 일정·페널티, 멘토/멘티 인원과 미성년자 보호, 앱 OS를 결정해야 한다.
